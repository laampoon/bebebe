# Практика C#

Консольный проект на языке **C#**, содержащий 50 практических заданий по основам программирования, объектно-ориентированному программированию, коллекциям, LINQ, асинхронности и работе с Git.

## Структура проекта

- `Task1.cs` — практические задания 1–14.
- `Task2.cs` — практические задания 16–34.
- `Extension.cs` — дополнительные методы расширения для `string`.
- `MenuRunner.cs` — консольное меню для выбора и запуска заданий.
- `Program.cs` — точка входа в программу.

## Описание программы

Программа позволяет выбирать и запускать выполненные практические задания через консольное меню. Задания сгруппированы по темам и доступны для отдельного запуска.

В проекте используются:
- Условные конструкции и циклы.
- Методы, массивы и строки.
- Коллекции и обобщения.
- LINQ и лямбда-выражения.
- ООП: классы, наследование, интерфейсы и полиморфизм.
- Обработка исключений.
- Асинхронное и параллельное программирование.
- Работа с файлами и JSON.
- Юнит-тестирование.

## Работа с Git

Проект находится под контролем версий Git.

Используемые правила:
- Основная ветка — `main`.
- Для разработки новых возможностей создаются отдельные `feature`-ветки.
- Сообщения коммитов оформляются по Conventional Commits.
- Перед объединением изменений используется Pull Request.
- Для объединения изменений применяются `merge` и `rebase`.
- Временные файлы Visual Studio и результаты сборки исключаются через `.gitignore`.

В рамках практических заданий также продемонстрированы `stash`, `reflog`, `bisect`, создание тегов и разрешение конфликтов слияния.
