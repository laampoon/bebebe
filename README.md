# Практика C#

Проект содержит выполненные практические задания по C#.

## Структура проекта

- Task1.cs — задания 1–14.
- Task2.cs — задания 16–34.
- Extension.cs — дополнительное задание.
- MenuRunner.cs — меню выбора заданий.
- Program.cs — точка входа в программу.

## Описание

Программа позволяет выбирать и запускать выполненные практические задания через консольное меню.

## Git

Проект находится под контролем версий Git.
Для разработки дополнительных возможностей используются отдельные ветки.
Ветка main: обновлённая основная версия проекта.
