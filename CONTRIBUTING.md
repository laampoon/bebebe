# Правила работы с проектом

## Ветвление

- main — основная стабильная ветка.
- feature/* — ветки для новых возможностей и заданий.

## Коммиты

Используем формат Conventional Commits:

- feat: новая функциональность
- fix: исправление ошибки
- docs: изменения документации
- chore: технические изменения
- refactor: изменение структуры кода без изменения поведения
- test: добавление или изменение тестов

## Pull Request

Перед слиянием изменений необходимо:

1. Проверить работоспособность проекта.
2. Убедиться, что изменения не содержат ошибок.
3. Описать выполненную работу в Pull Request.
